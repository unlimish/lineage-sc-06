# =============================================================================
# ISDB-T / 1seg (ワンセグ)
# =============================================================================
#
# Identified on a stock SC-06D (4.0.4, SC06DOMAMA2) with tools/oneseg-probe.sh
# and tools/analyze-oneseg-blobs.py. The names were not guessed: the probe
# searched the binaries for the literal "/dev/isdbt", and the tiers below
# follow the DT_NEEDED graph out from the one library that matched.
#
# The tiers matter. Do NOT uncomment all of this at once - see
# docs/07-実機調査の結果.md for why, and docs/05 for the order to work in.

# --- Tier 1: the minimum to reach the tuner -----------------------------
#
# libonesegdmxdriver.so is the ONLY object in the whole system image that
# opens /dev/isdbt. Its dependency set is remarkably small, and - this is the
# important part - it does NOT pull in libbinder, libandroid_runtime or
# libsurfaceflinger_client, the three things that would make a Jelly Bean
# blob unloadable on Pie.
#
#   libonesegdmxdriver.so -> libonesegutils.so -> libPGL.so
#                         -> liblog, libcutils, libutils, libc, libstdc++, libm
#
# Three proprietary files. That is the whole tuner path.
#
# lib/libonesegdmxdriver.so
# lib/libonesegutils.so
# lib/libPGL.so

# --- Tier 2: the stock TS demuxer -- NOT NEEDED -------------------------
#
# Design decision (2026-09): recording writes the received transport stream
# straight to a file, byte for byte, and CPRM is not implemented.
#
# That is not a shortcut past anything. 1seg is broadcast in the clear, so
# there is no scrambling on the reception path to undo. CPRM
# (libonesegcprmapi.so) is the wrapper Samsung applied to recordings it wrote
# to SD card, keyed from /efs/ - a format this app simply never produces.
# Writing a plain .ts is not "removing" CPRM; it is never adding it.
#
# What that decision removes from the port:
#
#   libonesegcprmapi.so    CPRM - and with it the /efs dependency
#   libsdtvcrypto.so       its crypto helper
#   libonesegdemux.so      Samsung's demuxer (libbinder, libandroid_runtime)
#   libsdtvphmem.so        its shared-memory plumbing
#   libBroadcastProcObs.so process observer
#   bin/OneSegTsDemux, bin/broadcastProcessObserver
#
# Recording and viewing become the same data path with two sinks: the bytes
# already in hand go to the decoder and, when recording, to a file as well.
# See docs/08-アプリ設計.md.
#
# One nuance worth knowing rather than discovering later: the stream carries
# broadcast copy-control signalling (digital_copy_control_descriptor). A
# receiver certified against the ARIB rules is expected to act on it. A
# personal recording on your own hardware is a different question from
# circumventing a protection measure - there is no protection measure on this
# path - but if this app were ever distributed as a product, that signalling
# is the part to revisit.

# --- Tier 3: service and EPG layer, and the app glue ---------------------
#
# The Java-facing side. Needed only if the stock application is the goal.
# Note that MobileTV_JPN.apk ships with a separate .odex, built against the
# 4.0.4 Dalvik boot classpath - it must be deodexed, and even then it targets
# an API level Pie will not treat kindly. Writing a small player is likely
# less work than making this run.
#
# lib/libSDtvService.so
# lib/libSDtvStack.so
# lib/libbroadcastForOneSeg_jni.so
# lib/libbroadcast_upgrade_jni.so
# lib/libOneSegfactorytest_jni.so
# app/MobileTV_JPN.apk

# --- Tier 4: data broadcasting (DSM-CC / BML) -- DO NOT PORT -------------
#
# This is データ放送, and the service is gone: NHK ended it 2025-03-30, TBS
# 2025-02-21, フジ 2025-03-31, テレ東 2025-04-20, テレ朝 2026-03-30, 日テレ
# 2026-03-31, TOKYO MX 2026-05-28. Porting it would be work for a signal that
# is no longer transmitted.
#
#   lib/libonesegdsmcc.so, lib/libonesegbmlpeer.so, lib/libsdsmcc.so
#   lib/libonesegsp.so, lib/libBML.so, lib/libBMLJNI.so, bin/OneSegDsmcc

# --- Tier 5: NexPlayer -- DO NOT PORT ------------------------------------
#
# libnexplayerservice.so is the stock video engine. It needs
# libsurfaceflinger_client.so, which does not exist on Android 9 at all, plus
# libandroid_runtime.so and libgui.so. It is not portable, and it does not
# need to be: MediaCodec decodes H.264 + AAC natively.

# --- Not 1seg, despite the name -----------------------------------------
#
# libMciAtscMh.so is ATSC-M/H, the US mobile TV standard. It mentions ISDBT
# in passing and is unrelated to ワンセグ. bin/at_distributor is the AT
# command daemon; it references ISDBT only for a factory-test command.
