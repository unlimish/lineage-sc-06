# 01. 結論と実現可能性 — どの道を選ぶか

SC-06D で「新しい Android」と「ワンセグ」を両立させたい、という話を、
判断できる形に分解します。

---

## 1. SC-06D は何者か

| 項目 | 内容 |
|---|---|
| 型番 | SC-06D（docomo GALAXY S III） |
| 発売 | 2012年6月28日 |
| SoC | Qualcomm Snapdragon S4 **MSM8960**（Krait 2コア 1.5GHz、32bit ARM） |
| RAM / ROM | 2GB / 32GB |
| 画面 | 4.8インチ 1280×720 Super AMOLED（xhdpi） |
| 純正 OS | Android 4.0.4 → **4.1.2 で打ち止め**（2013年6月） |
| ワンセグ | **対応**（伸縮式アンテナ）／フルセグは非対応 |
| モバキャス（NOTTV） | 非対応 |
| おサイフケータイ | 対応（NFC アンテナはバッテリー内蔵型） |
| カスタム ROM 上のコードネーム | **`d2dcm`** |
| カーネル内のボード名 | **`m2_dcm`**（`CONFIG_MACH_M2_DCM`） |

SoC が MSM8960 なので、SC-06D は Galaxy S3 の **`d2` ファミリ**（d2att / d2tmo / d2vzw / d2spr …）
の一員です。ここが重要で、**Exynos 版の i9300 とは別系統**です。

---

## 2. Android のバージョンはどこまで上げられるか

### 答え: Android 9（LineageOS 16.0）が上限

`d2` 系のツリーを実際に確認した結果です。

| リポジトリ | 最新ブランチ |
|---|---|
| `LineageOS/android_device_samsung_d2lte` | `cm-12.0`（Android 5.0） |
| `LineageOS/android_device_samsung_d2-common` | `cm-14.1`（Android 7.1） |
| `LineageOS/android_kernel_samsung_d2` | `lineage-15.0`（Android 8.0） |
| `Samsung-Galaxy-S3-MSM8960/android_kernel_samsung_d2` | **`lineage-16.0`（Android 9）** |
| `Samsung-Galaxy-S3-MSM8960/android_device_samsung_d2att-unified` | **`lineage-16.0`（Android 9）** |

有志（Samsung-Galaxy-S3-MSM8960）が lineage-16.0 まで持ち上げていて、そこで止まっています
（最終コミット 2020年12月）。**Android 10 以降の `d2` 向けツリーは存在しません。**

### 「Galaxy S3 で LineageOS 21 が動いてる」の話について

それは **Exynos 版の i9300 / i9305** です。あちらは mainline カーネル化の努力が続いていて、
LineageOS 20 / 21 の非公式ビルドがあります。**SC-06D（Snapdragon MSM8960）には適用できません。**
SoC もカーネルもグラフィックスドライバも別物です。

### それでも十分な前進

純正 4.1.2（Jelly Bean, 2012年）→ Android 9（Pie, 2018年）。
7 世代ぶんで、TLS 1.3、現代的な権限モデル、まともなブラウザが動く水準になります。

## 3. ワンセグはどうなるか

**核心はここです。** スタックを層に分けると、状況が一目でわかります。

```
┌─────────────────────────────────────────────┐
│ ワンセグアプリ（Samsung / docomo 製 .apk）   │ ← 純正のみ・Android 4.1 向け
├─────────────────────────────────────────────┤
│ TS 処理・RMP 復号・EPG（クローズドな .so）   │ ← 純正のみ・鍵を含む
├─────────────────────────────────────────────┤
│ NMI326 復調制御（クローズドな .so）          │ ← 純正のみ
├─────────────────────────────────────────────┤
│ /dev/isdbt  （SPI 生アクセス, major 225）    │ ← ★ここまでは新しい Android でも開いている
├─────────────────────────────────────────────┤
│ drivers/media/nmi326/  （GPL, ソースあり）   │ ← lineage-16.0 のカーネルに残存・有効
├─────────────────────────────────────────────┤
│ Newport Media NMI326 チューナ（SPI 接続）    │ ← ハードウェア
└─────────────────────────────────────────────┘
```

**下から 3 層は無料で手に入ります。** カーネルドライバは GPL でソースがあり、
しかも `lineageos_d2dcm_defconfig` で最初から `CONFIG_ISDBT_NMI=y` になっています。
つまり **LineageOS 16.0 をビルドすれば `/dev/isdbt` は出てきます**（ハードも生きているはず）。

**上から 3 層が丸ごと欠けています。** そしてそこに、

- チューニングと復調の全ロジック（ドライバは本当に SPI を叩くだけ）
- **RMP 鍵**（コンテンツ権利保護専用方式。2012年8月から順次導入、2013年3月27日に全国運用開始）
- Android 4.1 の API 前提で書かれたアプリ

が入っています。

### 過去に誰も通していない

CM13 時代の d2dcm デバイスツリー（`kbc-developers/android_device_samsung_d2dcm`）の
`device-proprietary-files.txt` を実際に見ると、こうなっています。

```
lib/libril.so, lib/libsec-ril.so     ← RIL（通話）
fonts/truetypeEmoji.ttf              ← 絵文字
lib/libemoji_docomo.so               ← docomo 絵文字
app/MobileFeliCaClient.apk ほか多数   ← おサイフケータイ
```

**ワンセグ関連が 1 つもありません。** FeliCa まで移植した人たちが、ワンセグには手を出していない。
これは「難しいから誰もやっていない」を強く示唆します。

### ワンセグ放送そのものは続いている（2026年9月現在）

- **データ放送は終了しました。** NHK が 2025年3月30日、TBS 系が 2025年2月21日、
  フジ系が 2025年3月31日、テレ東系が 2025年4月20日、テレ朝系の一部が 2026年3月30日、
  日テレ系が 2026年3月31日、TOKYO MX が 2026年5月28日に終了。
- **本放送（映像・音声）は継続中です。** 一斉終了の予定は総務省からも放送局からも出ていません。

つまり「映せれば見られる」状況は今も生きています。目標としては有効です。

## 4. 選択肢の比較

| 選択肢 | Android | ワンセグ | 難易度 | 向いている人 |
|---|---|---|---|---|
| **A. 純正 4.1.2 のまま root** | 4.1.2 | **確実に動く** | 低 | ワンセグが最優先 |
| **B. LineageOS 16.0（ワンセグ諦め）** | 9 | 動かない | 中 | 実用機として使いたい |
| **C. LineageOS 16.0 + ワンセグ移植** | 9 | **未知（本プロジェクト）** | 非常に高 | 挑戦したい |
| **D. LineageOS 16.0 + 外付けチューナ** | 9 | 別途要検証 | 中 | 折衷案 |

### A について

ワンセグが目的なら、これが最も確実です。ただし Android 4.1.2 は
TLS 1.2 すら怪しく、現代の Web はほぼ開けません。**「ワンセグ専用機」として割り切る**なら成立します。

### C について（このリポジトリの目標）

段階を踏めば、少なくとも**どこで詰まるかは特定できます**。

1. LineageOS 16.0 が起動する → ここは高確率で到達可能
2. `/dev/isdbt` が生えている → カーネル設定上ほぼ確実
3. 純正の .so が新しい Android のリンカで読める → **ここが最初の関門**
4. チューニングして TS が取れる → 関門を越えれば見込みあり
5. RMP 復号が通って映像が出る → **最大の関門**

3 で詰まったら 4 以降には進めません。ただし 2 まで到達した時点で
「ハードは生きている」ことが確認でき、その先の判断材料になります。

### D について

外付けの USB / microUSB ワンセグ・フルセグチューナ（PIXELA 製など）を使う案です。
ただし**専用アプリが古い Android 前提**であることが多く、Android 9 で動く保証はありません。
**購入前に、その製品の対応 Android バージョンを必ず確認してください。**
本リポジトリでは検証していません。

## 5. 推奨する進め方

**どの道を選ぶにせよ、最初にやるべきことは同じです。**

```bash
# 純正 4.1.2 + root の状態で
./tools/oneseg-probe.sh
```

これでワンセグスタックの実体（ファイル名・依存関係・鍵の所在）がわかります。
**LineageOS を焼いてしまうと取れなくなる情報**なので、必ず先にやってください。

その結果を見てから、B（諦める）か C（挑む）かを決めるのが合理的です。

---

## 6. 移行前に必ずやること

- [ ] **EFS パーティションのバックアップ**（IMEI が入っています。壊すと通信できなくなります）
- [ ] **純正 ROM 全体のバックアップ**（`tools/oneseg-probe.sh` とは別に、`/system` の丸ごと吸い出し）
- [ ] **おサイフケータイの残高移行**（カスタム ROM では FeliCa は動かないものと考えてください）
- [ ] 純正 ROM（Odin 用）の入手と、復旧手順の確認
