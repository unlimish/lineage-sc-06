## 1. ワンセグチューナは Newport Media NMI326 — **確認済み**

`android_kernel_samsung_d2` (lineage-16.0) より:

```
drivers/media/nmi326/Kconfig
drivers/media/nmi326/Makefile
drivers/media/nmi326/nmi326.c
drivers/media/nmi326/nmi326.h
drivers/media/nmi326/nmi326_spi_drv.c
drivers/media/nmi326/nmi326_spi_drv.h
```

`nmi326.h` の冒頭:

```c
/* linux/drivers/media/nmi326/nmi326.h
*
* Header file for NMI326 oneseg device
*
*  Copyright (c) 2012 Samsung Electronics
```

`Kconfig`:

```
config ISDBT_NMI
	bool "Samsung ISDB-T NMI Driver"
	default n
```

`drivers/media/Makefile`:

```
obj-$(CONFIG_ISDBT_NMI)	+= nmi326/
```

**NMI = Newport Media Inc.**（2014年に Atmel が買収、現 Microchip 傘下）。

## 2. デバイスノードは `/dev/isdbt`、char major 225 — **確認済み**

`drivers/media/nmi326/nmi326.h`:

```c
#define ISDBT_DEV_NAME		"isdbt"
#define ISDBT_DEV_MAJOR	225
#define ISDBT_DEV_MINOR	0
```

`nmi326.c` の `isdbt_probe()` は
`register_chrdev()` → `class_create()` → `device_create()` の順に呼ぶので、
**ueventd がノードを自動生成します**（`mknod` は不要）。

## 3. ioctl は 8 個だけ、復調ロジックは無い — **確認済み**

`nmi326.h`:

```c
#define IOCTL_MAGIC	't'

#define IOCTL_ISDBT_POWER_ON		_IO(IOCTL_MAGIC, 0)
#define IOCTL_ISDBT_POWER_OFF		_IO(IOCTL_MAGIC, 1)
#define IOCTL_ISDBT_INTERRUPT_REGISTER		_IO(IOCTL_MAGIC, 2)
#define IOCTL_ISDBT_INTERRUPT_UNREGISTER	_IO(IOCTL_MAGIC, 3)
#define IOCTL_ISDBT_INTERRUPT_ENABLE		_IO(IOCTL_MAGIC, 4)
#define IOCTL_ISDBT_INTERRUPT_DISABLE		_IO(IOCTL_MAGIC, 5)
#define IOCTL_ISDBT_INTERRUPT_DONE		_IO(IOCTL_MAGIC, 6)
#define IOCTL_ISDBT_INTERRUPT_HANDLER_START	_IO(IOCTL_MAGIC, 7)
```

チューニング・復調・TS 取得に相当する ioctl は **存在しません**。
`file_operations` は `read` / `write` / `poll` / `fasync` / `unlocked_ioctl` のみ。

→ **[`02-ワンセグの構造と壁.md`](02-ワンセグの構造と壁.md) の「ドライバは穴でしかない」の根拠。**

## 4. `CONFIG_ISDBT_NMI=y` が lineage-16.0 で有効 — **確認済み**

`arch/arm/configs/lineageos_d2dcm_defconfig` (lineage-16.0):

```
CONFIG_MACH_M2_DCM=y
CONFIG_ISDBT_NMI=y
CONFIG_ISDBT_NMI_DEBUG=y
CONFIG_SPI=y
CONFIG_SPI_MASTER=y
CONFIG_SPI_QUP=y
```

比較として、CM13 時代の `arch/arm/configs/cyanogen_d2dcm_defconfig`:

```
# CONFIG_ISDBT_NMI is not set
```

**CM13 では無効、lineage-16.0 では有効。** 誰かが Pie 化の過程で意図的に有効化しています。

## 5. SC-06D のボードは `m2_dcm`、SPI 結線あり — **確認済み**

`arch/arm/mach-msm/board-m2_dcm.c` (lineage-16.0) より:

```c
static struct spi_board_info isdbt_spi_info[] __initdata = {
	{
		.modalias		= "isdbtspi",
		.mode			= SPI_MODE_0,
		.bus_num		= 1,
		.chip_select	= 0,
		.max_speed_hz	= 5400000,
	}
};

static int __init isdbt_dev_init(void)
{
	isdbt_pdata.irq = MSM_GPIO_TO_INT(GPIO_ISDBT_INT);
	platform_device_register(&isdbt_device);
	isdbt_gpio_init();
	spi_register_board_info(isdbt_spi_info, ARRAY_SIZE(isdbt_spi_info));
	return 0;
}
```

電源シーケンス（`isdbt_gpio_on()`）:

```c
gpio_set_value_cansleep(PM8921_GPIO_PM_TO_SYS(PMIC_GPIO_ISDBT_EN), 1);
usleep_range(50000, 50000);
gpio_set_value_cansleep(PM8921_GPIO_PM_TO_SYS(PMIC_GPIO_ISDBT_RST), 0);
usleep_range(2000, 2000);
gpio_set_value_cansleep(PM8921_GPIO_PM_TO_SYS(PMIC_GPIO_ISDBT_RST), 1);
usleep_range(10000, 10000);
```

SPI コントローラは GSBI8（`msm8960_qup_spi_gsbi8_pdata`, `max_clock_speed = 15060000`）。

## 9. SELinux は permissive で動いている — **確認済み**

`android_device_samsung_d2att-unified/BoardConfig.mk`:

```makefile
BOARD_KERNEL_CMDLINE += androidboot.selinux=permissive
...
# SELinux
#include device/qcom/sepolicy/sepolicy.mk
#BOARD_SEPOLICY_DIRS += device/samsung/d2att/sepolicy
```

`BOARD_SEPOLICY_DIRS` はコメントアウト、カーネルコマンドラインで permissive 固定。

→ 移植の初期段階では有利（ポリシー不足で止まらない）。
`device/samsung/d2dcm/sepolicy/` は用意してあるが、既定では**コンパイルされません**。

## 11. RMP（コンテンツ権利保護専用方式）

**これも Web 情報です。**

- 一般社団法人 **地上放送RMP管理センター** が運用
- **2012年8月**から順次運用開始、**2013年3月27日**に全国運用開始
- 物理カードを使わず**ソフトウェアで実現**する前提。B-CAS と同じ**3重鍵暗号方式**
- 復号鍵を、B-CAS カードではなく**「鍵データ」として受信機に提供**する

出典: 地上放送RMP管理センター (trmp.or.jp)、日本語版 Wikipedia「コンテンツ権利保護専用方式」。
